📖 Metrics Glossary

Total Registered Users (All-time)

Formula: COUNT(*) FROM analytics_users

All-time cumulative count of registered users on the platform since launch (2024-11-29). This includes both active and inactive accounts. Each user has a verified email address.

DAU (Daily Page Views)

Formula: COUNT(*) FROM analytics_sessions WHERE date(session_start) = [target_date]

The total number of page views (sessions) recorded on a specific calendar day. Every session counts as one page view, including multiple sessions by the same user.

WAU (Weekly Page Views)

Formula: COUNT(*) FROM analytics_sessions WHERE date(session_start) BETWEEN date([ref], '-6 days') AND [ref]

The total number of page views (sessions) within the past 7 calendar days including the reference date. All sessions are counted, making this a volume metric rather than a unique-user metric.

MAU (Monthly Page Views)

Formula: COUNT(*) FROM analytics_sessions WHERE date(session_start) BETWEEN date([ref], '-29 days') AND [ref]

The total number of page views (sessions) within the past 30 calendar days including the reference date. This is a volume metric reflecting total platform traffic, not unique visitors.

Stickiness (DAU/MAU Ratio)

Formula: (DAU / MAU) × 100%

Measures how concentrated daily page views are relative to monthly total. A higher ratio indicates traffic is more evenly distributed across the month. Both DAU and MAU are page view counts, not unique user counts.

Bounce Rate

Formula: SUM(bounced_sessions) / SUM(total_sessions) over 7 days

The weighted percentage of sessions where users leave after viewing only one page. Uses sum-based calculation (not average) to properly weight high-traffic days. Lower is better; >40% may indicate UX issues.

New Users (Last 24h)

Formula: COUNT(*) FROM analytics_users WHERE created_at >= datetime('now', '-24 hours')

Users who registered within the last 24 hours relative to current time. This is a real-time metric that updates as new users sign up.

Sessions

Source: analytics_sessions table

A session begins when a user opens the app and ends after 30 minutes of inactivity or when explicitly closed. Each session tracks page views, duration, and user behavior.

Engagement Metrics (Composite Index)

Components: Scroll Depth, Clicks/Session, Active Time, Typing Events

A composite engagement index combining multiple normalized interaction metrics. Individual components are scaled to comparable ranges before aggregation. Higher values indicate deeper user interaction.

⚠️ Data Notes

Time Windows: WAU uses 7 calendar days (including today), MAU uses 30 calendar days (including today). All windows include the reference date.

Weighted Calculations: Bounce rate uses weighted averages (sum/sum) rather than simple averages to properly account for traffic volume differences.

Reference Date: All relative calculations use the most recent date with recorded activity, ensuring accurate historical analysis.
